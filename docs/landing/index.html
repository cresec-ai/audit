@edut/mcp-recorder

A black-box flight recorder
for MCP.

Wrap any MCP server in one config line. Every agent tool call is recorded, redacted at the edge, and sealed into a signed hash chain — on your machine. Nothing to trust, nothing to break.

$ mcp-recorder setup --client claude-desktop

Transparent stdio proxy · fail-open · <5ms p50 added latency · GPL-3.0

01Record

A transparent proxy forwards bytes unchanged and taps a copy. Payload strings never touch disk — each is replaced by its SHA-256 and length. If recording dies, your agent traffic keeps flowing.

02Prove

Every event is hash-chained and the head is signed with ed25519. Alter, insert, or delete any row and verify fails loudly. Export a signed bundle a stranger can check with bare Node — no dependencies, no account, no cloud.

03Reconstruct

Replay any session as an HTML timeline: see → act → effect, with identity context on every event. Hash a leaked value and ask the blast-radius question: which sessions touched this?
